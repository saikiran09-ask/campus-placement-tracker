# Campus Placement Tracker 🎓

A full-stack, responsive web application designed to bridge the gap between students and placement officers during campus recruitment drives. 

## Features
- **Role-Based Dashboards:** Distinct interfaces for Students and Admins.
- **Eligibility Engine:** Automatically checks if students meet the CGPA and branch restrictions before allowing them to apply for a job.
- **Application Tracking:** Students can seamlessly monitor their selection status and interview rounds.
- **Recruitment Management:** Admins can create companies, broadcast job openings, and accept/reject student applications.
- **Premium UI:** Powered by standard EJS and completely custom, modern CSS.
- **Built-in Analytics:** An Admin reporting dashboard overviewing recruitment metrics and salary data.

## Technology Stack
- **Frontend:** HTML5, Custom CSS, EJS
- **Backend:** Node.js, Express.js
- **Database:** Sequelize ORM with SQLite
- **Authentication:** Passport.js (Local Strategy, bcryptjs)

## Quick Start
1. Run `npm install` to grab the dependencies.
2. Run `npm start` to spin up the local server (Default port: 3000).
3. SQLite will automatically create `database.sqlite` in the root on your first run.
